Lee Premier Property Media booking and payment setup

The website now supports dynamic Stripe Checkout totals.

How payment works:

1. The customer selects a package and any add-on services on the website.
2. The website sends only the selected item names to a Netlify Function.
3. The Netlify Function validates the package and add-on prices on the server.
4. Stripe creates a secure Checkout page with the exact selected total.
5. The customer pays on Stripe.

Required Netlify environment variable:

STRIPE_SECRET_KEY

Add it in Netlify:

1. Open the Netlify site dashboard.
2. Go to Site configuration.
3. Go to Environment variables.
4. Add variable:
   Key: STRIPE_SECRET_KEY
   Value: your Stripe secret key
5. Redeploy the site after saving the variable.

Important:

Do not put the Stripe secret key in index.html, script.js, or any public file.
The secret key belongs only in Netlify environment variables.

Calendly:

Add the Calendly event booking URL to SITE_SETTINGS.schedulerUrl in script.js when available.
The inline calendar will then show available appointment times clients can select.

Calendly event setup:

1. Create or edit the photoshoot event type in Calendly.
2. Set the event duration to 180 minutes.
3. Configure availability so clients only see the 3-hour blocks you want to offer.
4. Copy the event booking URL and add it to SITE_SETTINGS.schedulerUrl in script.js.
